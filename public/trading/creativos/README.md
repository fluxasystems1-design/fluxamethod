# Creativos — landing `/trading`

Carpeta exclusiva para imágenes, videos y fondos de la página **https://tudominio.com/trading**.

## Dónde subir archivos en tu proyecto

Ruta en disco (copia/pega en el explorador de archivos):

```
fluxa-systems/public/trading/creativos/
```

## Subcarpetas

| Carpeta      | Qué va aquí                                      | Ejemplos                          |
|-------------|---------------------------------------------------|-----------------------------------|
| `fondos/`   | Fondos de página, texturas, overlays              | `fondo-hero.webp`, `trading-bg.png` |
| `hero/`     | Banners, mockups, imágenes del bloque principal   | `mockup-dashboard.png`            |
| `video/`    | VSL, poster del reproductor, thumbnail            | `vsl-trading.mp4`, `poster.jpg`   |
| `secciones/`| Ilustraciones por bloque (paquetes, FAQ, etc.)  | `growth-plan.png`                 |
| `iconos/`   | Iconos, badges, elementos pequeños                | `check-badge.svg`                 |

## Cómo se usan en la web

En el navegador la URL será:

```
/trading/creativos/[carpeta]/nombre-del-archivo.ext
```

Ejemplo: si subes `public/trading/creativos/video/vsl.mp4` → `/trading/creativos/video/vsl.mp4`

## Formatos recomendados

- **Imágenes:** WebP o PNG (fondos grandes &lt; 500 KB si puedes)
- **Video:** MP4 (H.264)
- **Nombres:** sin espacios, en minúsculas (`mi-banner.webp`)
